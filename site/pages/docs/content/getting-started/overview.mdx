Write text naturally in JSX. viteTranslate extracts the strings, keeps one `.yml` table per language in sync, and compiles the translations as part of your Vite workflow. ==No hand-written keys, no separate extraction step, no extra runtime dependencies.==

## What it is {#what-it-is}

A Vite plugin and a small React runtime, installed as one package. The plugin reads your source, the runtime shows the right sentence for the current language.

- **Less manual work.** Extraction and sync run inside Vite, not as a separate command to remember.
- **A light runtime.** The browser side weighs 5 kB gzip, ICU helpers included, and parses no messages: tables are compiled at build time.
- **Tools where you need them.** A [CLI](/api/cli) for sync, CI checks and guarded LLM translation; a [VS Code extension](/vscode/install) showing every string and its status.
- **Ready for real interfaces.** [ICU](/concepts/icu) plurals, select, numbers and dates; one lazy-loaded chunk per language; the source text as fallback until a translation exists; a safe subset of HTML tags.

It works with Vite 5 to 8 and React 18 or 19. Where it stands next to Lingui, FormatJS and i18next is in the [comparison](repo:README.md#-why-vitetranslate).

## The flow in four steps {#the-flow-in-four-steps}

1. **Write** the sentence where it belongs: `<Trans>Welcome back, <b>{name}</b>!</Trans>`. No key to invent. [Usage](/getting-started/usage#write-text-where-it-belongs)
2. **Sync**: at every `vite dev` start and before every build, new sentences go into `locale/en-US.yml`, stale ones out. [The table writes itself](/getting-started/usage#start-vite-the-source-table-writes-itself)
3. **Translate**: `npx vitetranslate --add fr-FR`, then fill the `null` values by hand or let an [LLM](/llm/setup) do it. [Add a language](/getting-started/usage#add-a-language)
4. **Ship**: `npm run build` compiles each language into its own chunk, loaded when selected. [Switch language and ship](/getting-started/usage#switch-language-and-ship)

## Runtime size {#runtime-size}

The browser runtime weighs 5 kB gzip, React itself left out. The ICU helpers are part of that number but ship only when a table uses ICU. ==Nothing else enters your bundle==: Babel and Vite run on your machine at `serve` and `build` time ([why](/getting-started/installation#it-never-reaches-your-bundle)).
