## What it is {#what-it-is}

One package, two halves: a Vite plugin that reads your source while you work, and a small React runtime that shows each sentence in the user's language.

- **Nothing to run by hand.** Extraction and sync happen inside Vite, every time the dev server starts and before every build.
- **A runtime you won't notice.** 5 kB gzip in the browser, ICU helpers included. It parses no messages: the tables are compiled at build time.
- **Tools when you want them.** A [CLI](/api/cli) for sync, CI checks and LLM translation with a guard on spending; a [VS Code extension](/vscode/install) that shows every string and where it stands.
- **Built for real interfaces.** [ICU](/concepts/icu) plurals, select, numbers and dates; one lazy-loaded chunk per language; the source text as a fallback until the translation lands; a safe subset of HTML tags.

It runs on Vite 5 to 8 with React 18 or 19. How it measures up to Lingui, FormatJS and i18next is in the [comparison](repo:README.md#-why-vitetranslate).

## The flow in four steps {#the-flow-in-four-steps}

From a sentence in your code to a language in production:

1. **Write** the sentence where it lives: `<Trans>Welcome back, <b>{name}</b>!</Trans>`. No key to invent. [Usage](/getting-started/usage#write-text-where-it-belongs)
2. **Sync**: start `vite dev`, or build. New sentences land in `locale/en-US.yml`, stale ones leave, and you never edit that file. [The table writes itself](/getting-started/usage#start-vite-the-source-table-writes-itself)
3. **Translate**: `npx vitetranslate --add fr-FR`, then fill the `null` values by hand, or hand them to an [LLM](/llm/setup). [Add a language](/getting-started/usage#add-a-language)
4. **Ship**: `npm run build` puts each language in its own chunk, downloaded only when someone picks it. [Switch language and ship](/getting-started/usage#switch-language-and-ship)

## Runtime size {#runtime-size}

Your users download 5 kB gzip of runtime, React itself left out. The ICU helpers are counted in that number, and they ship only when a table uses ICU. ==The rest stays on your machine==: Babel and Vite do their work at `serve` and `build` time and never reach the bundle ([why](/getting-started/installation#it-never-reaches-your-bundle)).
