Two pages, two jobs:

- 🎮 [Playground](site:playground) — each feature working, next to the code that produces it.
- 🧪 [Edge cases](site:edge) — where things bend: one row per case, what renders next to what should, ==the recommended forms first and the mistakes last== ([how to read it](site:edge#note)).

Both switch language live, and the `#` next to every title is a link to share. Each page of this manual links its own live cases too, right where it explains them, and every section of the two pages links back, under its title, to the page that explains it.
