The declarations ship with the package: nothing to install from `@types`. The React types come from `@sepoina/vitetranslate/react`, the plugin types from `@sepoina/vitetranslate`.

```tsx
import { Trans, type TranslateArg } from "@sepoina/vitetranslate/react";

export function Greeting({ name }: { name: TranslateArg }) {
  return <Trans>Welcome back, <b>{name}</b>!</Trans>;
}
```

## Values and arguments {#values-and-arguments}

| Type | What it is | Used in |
| :- | :- | :- |
| `TranslateArg` | One value that fits a placeholder: `ReactNode \| Date \| bigint` | [Translate](/components/translate#props) |
| `TranslateNamedArgs` | A plain object of named values, for `{name}` | [ICU arguments](/concepts/icu#arguments-positions-or-names) |
| `TranslateArgs` | A value, the named object, or a list of either | [Translate](/components/translate#props) |
| `TranslateObjectForm` | The object form: text and arguments together, `{ t, a }` | [Translate](/components/translate#other-forms) |
| `TranslateSource` | Everything that can sit in the text position: a string, a number, a ready element, the compact list or the object form | [Translate](/components/translate#what-can-sit-in-the-text-position) |
