## Domain
A Vite plugin plus a small React runtime (viteTranslate) that extracts marked strings from source, syncs them into per-language YAML tables, and renders the right sentence at runtime. Ships with a CLI, a VS Code extension, and optional LLM-powered translation. Docs cover installation, markers, ICU messages, plurals/dates, preloading, and migration from 3.x.

## Register
Developer-facing technical documentation: direct, second-person, instructional, with occasional playful touches (emoji, "Ada", a restaurant example). Short UI labels and table headers are terse and noun-like, not sentences.

## Ambiguities
Bare labels ("Value", "Type", "Field", "Command", "ID", "Description", "Count", "Mode", "Where", "Does", "Back") are table headers or panel labels with no sentence context.
Callout labels ("Caution", "Note", "Important", "Warning", "Tip") are severity names, not sentences.
"Copy" / "Copied" are a button and its confirmation state, not the same string.
"default ({0})", "off", "English" are option values or list entries, not prose.
"Page not found" and "This address is not in the manual." are 404 text; the second is deliberately playful.
"The context abstract" uses "abstract" as a noun (the LLM brief), not an adjective.
"Regenerates", "never — but still reads the file if it exists", "only on {0}" are fragments answering an implicit question in a table.
"3k / 100" and "4,096" are numeric values; keep digits and separators.
"Выбрано: 2 файла", "Lingua della pagina", "Cambia tema" are already in Russian/Italian as illustrative samples, not source text.
"Menu", "Switch theme", "← Previous", "Next →", "On this page" are app/docs chrome, not body prose.
