# Vite 8 + React 19 (solo JS/JSX)

Setup minimale, senza TypeScript, con ESLint 10 in flat config.

## Uso

```bash
npm install
npm run dev      # dev server
npm run build    # build di produzione (Rolldown)
npm run preview  # anteprima della build
npm run lint     # ESLint
```

## StackBlitz

Importa lo zip da https://stackblitz.com (New project > Import).
Vite 8 usa Rolldown: in WebContainer viene installato automaticamente il binding WASM.
